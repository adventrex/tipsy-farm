# tipsy.farm
Static site for Tipsy Bee Farms (no build step). Served by GitHub Pages from `main` / root; custom domain via `CNAME`.
Rooms: estate (`/`), `/rooms/`, `/hive/`, `/orchard/`, `/lineage/`, `/cellar/`, `/arcade/`, `/flight/`, `/quest/` (contact), `/guide/`.
Contact form posts to a Google Apps Script web app (`ContactFormScript.gs` in the old repo); fallback is mailto:hello@tipsy.farm.
Rule: no mead is sold, no street address, no grant/EIN/remittance internals on the public site.
